**React Dashboard • SQL • Machine Learning • IoT**

### 📄 DocuChat — Full-Stack AI Document Assistant

**React.js • Python • RAG • LangChain • Embeddings • Database**

Built an end-to-end document AI pipeline — **Parse → Chunk → Embed → Retrieve → Generate** — with a React frontend, Python backend, database-backed processing, and third-party AI APIs.

### 🧭 Skill Map AI — Career Guidance Platform

**Python • Gemini API • Tavily Search • Jobs API • React.js**
